# Склад Евгения — skladvrn.ru

Одностраничный сайт-визитка склада складских остатков кабеля и противопожарного
оборудования в Воронеже. Хостится на **GitHub Pages** с собственным доменом.

## Адреса

| Что | Где |
|---|---|
| Сайт | https://skladvrn.ru/ |
| Репозиторий | https://github.com/osagovrn/Sklad |
| Ветка | `main` (публикуется автоматически) |

## Как работает каталог

Каталог товаров живёт в **Google-таблице** (колонки: `Категория | Название |
Количество | Цена | Заметка | Фото`). Ссылка на CSV-эндпоинт задана в
`index.html` в константе `CATALOG_SHEET_CSV_URL`.

Два механизма:

1. **Живой каталог (для посетителей)** — браузер сам скачивает CSV через
   JavaScript и показывает товары с поиском и фильтрами по категориям.
2. **SEO-слепок (для поисковиков)** — workflow `update-catalog.yml` каждые
   6 часов (и по кнопке «Run workflow» в Actions) скачивает CSV, вшивает
   список товаров и ItemList JSON-LD прямо в `index.html` между метками
   `STATIC_CATALOG_START` / `STATIC_CATALOG_END`, обновляет `lastmod` в
   `sitemap.xml` и **сам публикует сайт на Pages**.

**Чтобы обновить каталог**: отредактируйте Google-таблицу — в течение
6 часов (или сразу по кнопке) сайт обновится автоматически, ничего вручную
коммитить не нужно.

## Как задеплоить изменения вручную

```bash
git add -A
git commit -m "Описание изменений"
git push origin main
```

Push в `main` автоматически публикует сайт через `pages.yml`.

## Примечания

- Фото в `index.html` встроены как base64 **намеренно** — не заменять на
  внешние файлы и не «оптимизировать»: при конвертации пропадает фон склада
  за фото катушки.
- Домен `skladvrn.ru` зарегистрирован до **30.07.2027** — не забыть продлить.
