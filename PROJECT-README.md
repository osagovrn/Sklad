# Склад Евгения — сайт skladvrn.ru

Одностраничный сайт-визитка для продажи складских остатков кабеля и
противопожарного оборудования (компания-владелец: ООО Фирма «Виксер», Воронеж).

## Домен

- **Адрес:** https://skladvrn.ru
- **Куплен:** 30.07.2026
- **Срок регистрации:** 1 год
- **⚠️ Продлить до:** 30.07.2027 (иначе сайт станет недоступен)

## Структура файлов

| Файл | Назначение |
|---|---|
| `index.html` | Весь сайт — вёрстка, стили и JS-логика в одном файле |
| `sitemap.xml` | Карта сайта для поисковиков (Яндекс + Google) |
| `robots.txt` | Разрешает индексацию, указывает на sitemap.xml |
| `PROJECT-README.md` | Этот файл — описание проекта |

Все файлы должны лежать в **корне** сайта на хостинге (там же, где `index.html`).

## Что сделано

### Контент и SEO
- Мета-теги (title, description, keywords), Open Graph и Twitter-карточки для превью в соцсетях
- Микроразметка Schema.org (`Store`) с адресом, телефоном, реквизитами компании
- `sitemap.xml` и `robots.txt` добавлены и подключены к обеим поисковым системам
- Подтверждение прав на сайт:
  - **Яндекс.Вебмастер** — через мета-тег `yandex-verification`
  - **Google Search Console** — через мета-тег `google-site-verification`

### Аналитика
- **Яндекс.Метрика** (счётчик id `111175891`) — с Вебвизором, картой кликов, отслеживанием ссылок

### Функциональность каталога
- Каталог товаров подгружается динамически из **Google-таблицы** (публикуется как CSV-ссылка,
  переменная `CATALOG_SHEET_CSV_URL` в `<script>` внизу `index.html`)
- Работает "умный" поиск по каталогу: не чувствителен к раскладке клавиатуры (рус/англ),
  похожим буквам, регистру
- Фильтрация по категориям (кабель / пожарное оборудование / другое)
- При проблемах с CORS — запасной путь загрузки через прокси `allorigins.win`

### Форма заявки
- Заявки с формы на сайте уходят одновременно в **Telegram** (через бота) и **на почту**
  (через сервис Web3Forms) — реализовано с резервированием: если один канал не сработал,
  заявка всё равно уйдёт по второму
- Есть проверка обязательных полей (телефон, согласие на обработку персональных данных)

### Юридическая часть
- Блоки «Политика конфиденциальности» и «Публичная оферта» (черновик, стоит показать юристу)
- Согласие на обработку персональных данных согласно 152-ФЗ

## Технические заметки

- Сайт — статический HTML/CSS/JS без сборки и фреймворков, открывается как обычный файл
- Все скрипты и стили встроены прямо в `index.html` (единый файл, легко переносить)
- Ключи и токены (Telegram-бот, Web3Forms) хранятся прямо в коде — если понадобится
  сменить, искать по комментариям `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `WEB3FORMS_ACCESS_KEY`
